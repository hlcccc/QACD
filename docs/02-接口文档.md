# QACD 接口文档

本文档定义平台侧对接所需的四个接口。所有接口的字段名、类型、取值域**冻结**，
如需改动必须升 `version` 并同步更新本文件。

- 服务基址：由部署方决定，示例 `http://<host>:8080`
- 内容类型：`application/json`（UTF-8）
- 版本标识：响应体 `version` 字段 + `GET /health` 的 `service_version`
- 错误约定：参数/计算错误返回 `400`，body 为 `{"detail": "<原因>"}`

接口与三个"真值"来源的一致性由 `tests/` 覆盖，可直接用于对接前的自测。

## 技术点 1 — `POST /v1/qacd/risk`

完整回答错误风险评分。**这是平台的主对接接口。**

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `question` | string | 是 | VQA 问题原文 |
| `answer` | string | 是 | 待评分的冻结 LVLM 回答 |
| `image` | string | 否 | 图像路径 / URL / 不透明标识，默认 `""` |
| `threshold` | float | 否 | 覆盖冻结告警阈值（仅影响 `is_high_risk`，不影响 `risk_score`） |
| `return_claims` | bool | 否 | 是否返回逐主张明细，默认 `true` |

```json
{
  "question": "What brand is the camera?",
  "answer": "Dakota digital",
  "image": "/data/textvqa/val/eb38600d8a5ade9a.jpg",
  "return_claims": true
}
```

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `risk_score` | float `[0,1]` | **回答级错误风险**，越大越可能出错 |
| `is_high_risk` | bool | `risk_score >= threshold` |
| `threshold` | float | 本次生效的阈值 |
| `num_claims` | int | 分解出的主张数（1..8） |
| `claims` | array | 逐主张风险明细，见下 |
| `feature_dim` | int | 打分器使用的特征维度（用于版本核对） |
| `model_calls` | int | 本次评分产生的模型调用次数（成本核算用） |
| `latency_ms` | int | 服务侧处理耗时（毫秒） |
| `version` | string | 打分器版本 |
| `warnings` | array[string] | 非致命告警，**必须记录**，见"告警语义" |
| `channels` | object | 各证据通道的中间量，用于审计与路由 |

`claims[]` 元素：

| 字段 | 类型 | 说明 |
|---|---|---|
| `claim_id` | string | 形如 `c1`, `c2` |
| `claim_text` | string | 问题条件化后的主张文本 |
| `claim_type` | string | 11 类词表之一，见 `qacd/types.py` |
| `risk` | float `[0,1]` | 该主张的错误风险 |

```json
{
  "risk_score": 0.279777,
  "is_high_risk": false,
  "threshold": 0.5,
  "num_claims": 1,
  "claims": [
    {"claim_id": "c1",
     "claim_text": "The answer to the question 'What brand is the camera?' is Dakota digital.",
     "claim_type": "OCR_text",
     "risk": 0.279777}
  ],
  "feature_dim": 48,
  "model_calls": 2,
  "latency_ms": 3,
  "version": "1.0.0",
  "warnings": [],
  "channels": {"evidence_score": 0.279777, "mvr_unsupported_rate": 0.333333}
}
```

### 告警语义（平台必须处理）

| 告警文本关键字 | 含义 | 平台动作建议 |
|---|---|---|
| `scorer is not fitted` | 打分器未拟合，返回的是**未校准先验**，不是 QACD 概率 | 拒绝入库/打标，仅用于联调 |
| `claim set validation` | 分解未通过覆盖率/原子性校验 | 记录，该条风险置信度下降 |
| `fusion head is not fitted` | MVR 特征已算但融合头未拟合，返回证据分 | 记录，`channels.fused_score` 缺失属预期 |

## 技术点 2 — `POST /v1/qacd/mvr`

多视图重采样一致性。供平台在**不想跑完整 QACD**、只想拿稳定性信号时单独调用；
也可用于自建融合头。

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sampled_answers` | array[string] | 是 | **同一 prompt** 的 K 次采样生成，按采样顺序 |
| `ocr_texts` | array[string] | 否 | 该图像 OCR 出的文字框 |
| `k` | int | 否 | 使用前 K 条；默认全部 |

### 出参

| 字段 | 类型 | 取值 | 说明 |
|---|---|---|---|
| `k_used` | int | ≥1 | 实际使用的采样数 |
| `features.mvr_unsupported_rate` | float | `[0,1]` ↑风险 | 未被图像文字支撑的采样比例 |
| `features.mvr_all_unsupported` | float | `{0,1}` ↑风险 | 全部采样都不被支撑 |
| `features.mvr_all_supported` | float | `{0,1}` ↓风险 | 全部采样都被支撑 |
| `features.mvr_fuzzy_mean` | float | `[0,1]` | 模糊相似度均值 |
| `features.mvr_fuzzy_min` | float | `[0,1]` | 模糊相似度最小值 |
| `features.mvr_fuzzy_std` | float | ≥0 | 模糊相似度标准差 |
| `features.mvr_fuzzy_best_of_k` | float | `[0,1]` | 模糊相似度最大值 |
| `note` | string | | 说明文字 |

> 该通道**不是独立检测器**。冻结配置下这 7 个特征由响应级逻辑融合头与证据分联合消费。

## 技术点 3 — `POST /v1/qacd/mechanical`

机械 OCR 仪器通道。输入主张文本与图像 OCR 结果，输出确定性的重叠统计。

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `claim_text` | string | 是 | 主张文本（或未分解的原始回答） |
| `ocr_texts` | array[string] | 否 | OCR 文字框 |
| `ocr_scores` | array[float] | 否 | 逐框置信度；缺省按 1.0 |

### 出参

`features` 含 19 项 OCR 子族特征，命名前缀 `mech_ocr_`。方向约定：

- 支撑方向：`mech_ocr_exact_present`、`mech_ocr_containment_present`、
  `mech_ocr_all_words_present`、`mech_ocr_best_similarity`、`mech_ocr_best_token_recall`、
  `mech_ocr_best_token_precision`、`mech_ocr_char_coverage`、`mech_ocr_number_present`、
  `mech_ocr_best_match_confidence`、`mech_ocr_best_similarity_conf`、`mech_ocr_text_density`、`mech_ocr_n_strings`
- 风险方向（越大越危险）：`mech_ocr_absent_risk`、`mech_ocr_low_similarity_risk`、
  `mech_ocr_low_recall_risk`、`mech_ocr_low_char_coverage_risk`、`mech_ocr_number_missing_risk`、
  `mech_ocr_empty`、`mech_ocr_has_number`

`family_size_in_frozen_config` 返回冻结配置中完整机械族的维度（28），
提醒本端点只实现了其中的 OCR 子族。

### 边界行为

- `ocr_texts` 为空 → `mech_ocr_empty = 1.0`，`mech_ocr_absent_risk = 1.0`，**不报错**。
- 该通道面向**含场景文字**的图像设计。图像无场景文字时该通道不携带信息，
  平台应先在自己的数据分布上确认文字覆盖率，再决定是否赋予该通道权重。

## 技术点 4 — `POST /v1/qacd/select`

保形选择性预测与弃权。在校准集（已知正确样本的风险分）上构造 class-conditional
conformal p-value，再用 BH（独立性/PRDS）或 BY（任意依赖）多重性程序选出可接受的
图像/回答子集。

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `calibration_null_scores` | array[float] | 是 | 校准集中**已知正确**样本的风险分 |
| `test_scores` | array[float] | 是 | 待判定样本的风险分 |
| `alpha` | float `(0,1)` | 否 | 目标错误率，默认 0.10 |
| `procedure` | string | 否 | `"BY"`（任意依赖，主程序）或 `"BH"`（独立性/PRDS 诊断） |
| `test_labels` | array[int] | 否 | **仅用于回报** realized FDP，不参与选择 |

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `accepted` | array[bool] | 每个测试样本是否被接受（保留） |
| `num_accepted` / `num_items` | int | 接受数 / 总数 |
| `coverage` | float | `num_accepted / num_items` |
| `procedure` / `alpha` | | 回显 |
| `realized_fdp` | float \| null | 传入 `test_labels` 时才有值 |
| `validated` | bool | 过程状态标志，供调用方在代码中 gate |
| `notes` | array[string] | 状态说明；无接受项时会明确提示 |

## `GET /health`

```json
{
  "status": "ok",
  "service_version": "1.0.0",
  "scorer_version": "1.0.0",
  "scorer_fitted": true,
  "feature_dim": 48,
  "mvr_enabled": true,
  "conformal_validated": false
}
```

平台应在启动时校验 `scorer_fitted == true`，否则拒绝将 `risk_score` 写入业务库。

---

## 版本与兼容性约定

1. `feature_dim` 变化 = **不兼容变更**，平台侧应做硬校验。
2. `channels` 是**附加**信息，平台不得依赖其中任何字段做决策；字段可增删。
3. 打分器以纯 JSON 导出（`qacd fit --out scorer.json`），**不包含 pickle**，可安全跨环境分发。
4. 请求/响应字段一旦冻结，只能新增、不能改语义。
