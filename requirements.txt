# QACD core runtime — deliberately minimal.
# The decision layer (decomposition parsing, feature assembly, BIC-lite
# calibration, MVR statistics, response aggregation, conformal selection) and
# the evaluation layer are implemented with NumPy only, so the package installs
# and is testable on a CPU-only machine with no model weights.
numpy>=1.23
# The documented quick start (`pip install -r requirements.txt && pytest`) runs
# the whole suite, and the frozen feature engineering needs pandas. The decision
# layer (`qacd/`) and the metrics (`evaluation/`) themselves stay NumPy-only.
pandas>=1.5
