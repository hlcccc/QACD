# QACD 方法说明

> Question-Conditioned Atomic Claim Decomposition
> 问题条件化原子主张分解 —— 面向 LVLM 视觉问答的回答级错误风险后处理评分
## 1. 一句话概括

QACD 是一个**后处理**的回答错误风险评分流程：不改动、不重训视觉语言模型，把冻结 LVLM
产生的回答（answer）连同问题（question）和图像（image）作为输入，输出一个 `[0,1]` 的
**回答级错误风险分数**，以及可选的逐主张风险明细。

适用场景：预警、人工复核分流、拒答/弃权决策、以及平台侧的回答质量看板。

## 2. 它解决什么问题

LVLM 在视觉证据不足时会生成流畅但错误的回答。现有风险信号各有短板：

- **模型自报置信度**（raw confidence）几乎无排序能力（冻结测试 AUROC 0.49，接近随机）。
- **多采样一致性**（SelfCheckGPT / multi-sample consistency）有效，但只看"多次生成是否一致"，
  当模型稳定地犯同一个错时无法发现。
- **纯模态验证**（让模型自己看图判断回答对不对）过于自信：诊断显示它在约 **94%** 的回答上
  都判"有支持"，其残余信号主要来自主张与它自己吐出的证据串之间的字面重合。

QACD 的思路是：**先把回答拆成"能被独立验证的原子主张"，再用确定性的、非模型的证据通道去
核对，最后用一个小的正则化逻辑校准器把证据映射成概率。**

## 3. 流程

```
                  image ──────────────┐
                                      │
 question ──┐                         ▼
            ├──► ① 问题条件化原子主张分解 ──► {c1..cn}
 answer ────┘                │
                             ├──► ② 信念一致性视图（4 视图）
                             ├──► ③ 类型化直接验证（多模态）
                             ├──► ④ 证据-主张对齐特征
                             └──► ⑤ 机械 OCR 仪器通道（对比主张串与图像文字）
                                      │
                                      ▼
                            ⑥ BIC-lite 逻辑校准器（λ = 0.05）
                                      │
                                      ▼
                            ⑦ 最大值算子聚合 → 回答级证据分
                                      │
                       ⑧ （可选）MVR 多视图重采样一致性 → 响应级融合
                                      │
                                      ▼
                                  风险分数
```

### ① 问题条件化原子主张分解

短回答脱离问题不是自包含命题。例如问题是"这台相机是什么品牌？"，回答是"Dakota digital"——
孤立的名词短语无法被验证。QACD 把问题作为分解语境，产出：
`The answer to the question 'What brand is the camera?' is Dakota digital.`

每条主张带：主张类型（11 类词表）、验证类型路由（direct / ocr / hard / indirect）、
原子性分数、词面忠实度、是否需外部知识、以及一个类型化的 yes/no 验证提示。

**两条路径并存，且都是部署系统的一部分：**

| 路径 | 说明 | 开发集占比 |
|---|---|---|
| 受检 LLM 分解 | 约束 JSON prompt + 覆盖率/原子性/忠实度校验 | 34.8% |
| 确定性规则回退 | 按句/小句切分并注入问题语境 | 65.2% |

覆盖率低于 0.8、出现重复主张、或存在非原子主张时判定分解无效并走回退。
主张数上限 `M_max = 8` 是**实现层面的成本约束，不是调优出来的最优值**——项目不主张 8 最优。

### ② 信念一致性视图

每条主张经过 4 个视图：独立回答、视觉回答、去掉该主张后的回答、答案生成后的主张匹配。
产出支持度、置信度、答案相似度、分歧度、不确定性与交互特征。

### ③ 类型化直接验证

按主张类型路由到不同的证据探针（计数 / OCR / 实体 / 物体存在 …），给出
支持 `p_s`、矛盾 `p_c`、证据存在 `p_e`、不确定性 `u`，并组合出可解释的直接风险摘要。
**该摘要是校准器的输入特征之一，不是最终分数。**

### ④ 证据-主张对齐

即使证据串与主张毫无字面关系，验证器也可能给出高置信度。QACD 用归一化字符相似度 `S`
与内容词覆盖率 `T` 度量对齐程度，两者同量纲等权合成；权重不是拟合出来的。

### ⑤ 机械 OCR 仪器通道

把"模型判断"换成"确定性比对"：用 OCR 读出图像中的文字，与主张串做精确匹配、包含、
序列相似度、词召回/精确率、字符覆盖、数字存在性等 19 项 OCR 子族特征（完整机械族 28 维，
另含 CLIP 探针与计数探针）。

动机来自诊断：主张文本出现在图像文字中的比例，正确答案为 **64.8%**，错误答案仅 **37.1%**。
纯机械通道单独即可达到 AUROC 0.7431。

### ⑥ BIC-lite 风险校准

对方向对齐后的特征做中位数填补与 z-score 标准化，再最小化 L2 正则化逻辑目标：

```
mean( log(1 + exp(z)) − y·z ) + λ·‖w‖² ,   z = b + Xw ,   λ = 0.05
```

注意惩罚项加在**平均**负对数似然上，不是求和上。特征选择、缺失填补、标准化与系数拟合
**只使用开发集**，冻结测试标签不参与任何变换、系数、特征集、阈值或超参选择。

### ⑦ 回答级聚合

`r_i = max_j r̂_ij` —— 保守的"任一主张高风险即预警"规则。
代价是已知的：一条解析错误的主张会抬高整条正确回答的分数。

### ⑧ MVR 多视图重采样一致性

对**同一个 prompt** 采样 K 次生成，把每个采样串与图像 OCR 文字做机械核对，得到
不支撑比例、全不支撑、全支撑、模糊相似度的均值/最小/标准差/最优等 7 项稳定性特征，
再与回答级证据分一起过一个响应级逻辑融合头。

K 是成本/精度旋钮：

| K | AUROC | Brier | 每回答生成调用 | 相对 K=0 的 ΔAUROC | 95% CI |
|---:|---:|---:|---:|---:|---|
| 0（仅 LM+机械） | 0.8382 | 0.1587 | — | — | — |
| 2 | 0.8448 | 0.1562 | 2 | +0.0066 | [0.0024, 0.0107] |
| 3 | 0.8498 | 0.1539 | 3 | +0.0116 | [0.0053, 0.0178] |
| 5 | **0.8526** | **0.1529** | 5 | +0.0144 | [0.0070, 0.0219] |

## 4. 主要结果（冻结 TextVQA 测试集）

集合规模：1,999 条回答 / 1,278 张未参与开发的图像 / 836 条失败（41.8%）。

| 方法 | 回答级 AUROC | 图像级 AUROC |
|---|---:|---:|
| QACD LM-only | 0.7989 | 0.8225 |
| QACD LM + 机械仪器 | 0.8346 | 0.8537 |
| QACD LM + MVR | 0.8349 | 0.8453 |
| **QACD LM + 机械仪器 + MVR** | **0.8495** | **0.8608** |
| UMPIRE K=5（白盒，借用了模型内部量） | 0.8564 | 0.8561 |
| SelfCheckGPT-NLI K=5 | 0.8319 | 0.8477 |
| Multi-sample Consistency K=5 | 0.8258 | 0.8363 |

主配置（LM + 机械 + MVR K=5）与基线的配对图像级 bootstrap（5,000 次）：

| 对比 | ΔAUROC | 95% CI | 结论 |
|---|---:|---|---|
| vs UMPIRE K=5（白盒） | −0.0039 | [−0.0195, +0.0124] | **持平**（区间跨 0） |
| vs SelfCheckGPT-NLI K=5 | +0.0207 | [+0.0028, +0.0391] | 领先 |
| vs Multi-sample Consistency K=5 | +0.0267 | [+0.0102, +0.0436] | 领先 |

关键点：QACD 是**黑盒**方法（只需回答文本 + 图像文字），与需要模型内部量的白盒方法 UMPIRE
打成统计持平。

## 5. 代码结构

```
qacd/
  types.py       数据容器与主张类型词表
  decompose.py   ① 问题条件化原子主张分解（受检 LLM + 规则回退）
  features.py    特征装配（顺序即冻结系数所绑定的顺序）
  align.py       ④ 证据-主张对齐
  mechanical.py  ⑤ 机械 OCR 通道 + ⑧ MVR 统计
  calibrate.py   ⑥ BIC-lite 校准器（NumPy 阻尼牛顿法，无 sklearn 依赖）
  aggregate.py   ⑦ 最大值算子
  conformal.py   保形选择性预测（BH / BY）
  pipeline.py    端到端编排 + 打分器导出/加载（纯 JSON，无 pickle）
  providers.py   证据提供方接口（Mock / RapidOCR / LLaVA 适配器）
  service.py     HTTP 服务（4 个对接端点）
  cli.py         命令行入口
```

**参考实现的特征通道规模与研究流水线不同**：本仓库产出 LM 证据子族 + 对齐 + 交互 +
机械 OCR 子族；研究流水线的冻结打分器消费 95 维 LM 向量与 28 维机械族。
两者通过 `qacd/features.py` 的 `FEATURE_SCHEMA_VERSION` 与命名契约隔离，不会混淆。
